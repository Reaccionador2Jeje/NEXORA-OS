NEXORA OS es un proyecto basado en Debian que ofrece dos formas de usar tu equipo: un entorno Minimal centrado en la terminal y una experiencia de escritorio XFCE personalizable.

Elige tu experiencia

Dos ediciones. Tu manera de trabajar.

Ambas parten de Debian 13 Trixie y comparten el objetivo de mantener el sistema claro, accesible y adaptable.

Ligero · Terminal

NEXORA Minimal

Una base sencilla para quienes prefieren trabajar desde la línea de comandos y construir su propio entorno.

  • Sin entorno de escritorio preinstalado
  • Utilidades estándar del sistema
  • Ideal para terminal, desarrollo y personalización
  • Instalación mediante Debian Installer
No incluye navegador, juegos ni escritorio por defecto.
Escritorio · XFCE

NEXORA XFCE

La experiencia gráfica de NEXORA, con un escritorio XFCE y herramientas propias integradas.

  • Entorno de escritorio XFCE
  • Fondos y temas visuales NEXORA
  • Welcome, Store y Control Center
  • Cliente NEXORA AI configurable
El cliente de IA requiere configurar un servicio compatible; no incluye modelos ni credenciales.
Diseñado para elegir

Lo esencial, sin complicaciones.

NEXORA mantiene las ediciones diferenciadas para que instales solamente la experiencia que necesitas.

Basado en Debian

Construido sobre Debian 13 Trixie para amd64 y su ecosistema de paquetes.

Personalización

La edición XFCE integra temas y fondos propios para adaptar el escritorio.

Software abierto

El proyecto publica su desarrollo y configuración en un repositorio público.

Cómo empezar

Prepara tu instalación

El instalador está basado en Debian Installer GTK. La instalación necesita conexión de red para descargar los paquetes.

Revisa el proyecto

Consulta los perfiles, requisitos y estado actual en el repositorio oficial.

Obtén la imagen

Cuando haya una compilación publicada, estará disponible desde los artefactos o lanzamientos del proyecto.

Instala con cuidado

Prueba primero en una máquina virtual. Revisa el disco seleccionado: el particionado debe hacerse de forma interactiva.

Proyecto en desarrollo

NEXORA OS todavía está en fase de integración y pruebas. La imagen netinst, el arranque BIOS/UEFI y la instalación completa deben validarse antes de considerarla una versión estable. El instalador gráfico aún conserva la interfaz original de Debian. Consultar compilaciones y CI ↗
