# NEXORA OS — Brand guide

**Tagline:** Your Terminal. Your Universe.

## Identity

NEXORA OS uses a geometric N mark crossed by an orbital path. The mark represents exploration, connected systems, and user freedom.

## Palette

| Token | Hex | Use |
|---|---|---|
| Space | `#080B1B` | Dark surfaces and backgrounds |
| Deep violet | `#171044` | Secondary dark surfaces |
| Electric violet | `#6545F5` | Primary accent |
| Nebula magenta | `#D946EF` | Secondary accent |
| Plasma cyan | `#22D3EE` | Highlights and focus |
| Starlight | `#F8FAFC` | Main text on dark surfaces |

## Assets

- `logo/nexora-logo.svg`: horizontal logo and tagline.
- `logo/nexora-icon.svg`: square application and system icon.

Keep SVG assets scalable. Do not rasterize the master logo for desktop panels or login screens unless a target format requires it.

## Usage

Prefer the icon without the wordmark in compact UI surfaces. Use the horizontal logo on welcome screens, documentation, and promotional material. Maintain contrast and clear space around the mark.
