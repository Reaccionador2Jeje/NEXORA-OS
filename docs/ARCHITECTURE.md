# NEXORA OS Architecture

## Overview

NEXORA OS is a Debian-derived operating system assembled with Debian Live's `live-build` tooling. The project keeps its configuration in version control so that the image can be rebuilt from documented inputs.

## Layers

1. **Debian base** — package repositories, kernel, init system and system utilities.
2. **Live image** — bootable filesystem and bootloader generated by live-build.
3. **Desktop** — KDE Plasma, SDDM and selected desktop applications.
4. **NEXORA integration** — future integration of the NEXORA terminal and supporting tools.
5. **Branding** — future wallpapers, icons, Plymouth theme and installer artwork.

## Editions

- **Desktop:** KDE Plasma workstation; first development target.
- **Server:** server-focused package selection and service defaults; planned after Desktop.
- **Core:** minimal base for custom deployments; planned after the build pipeline is stable.

## Build flow

```text
Git repository
    |
    v
auto/config + config/package-lists
    |
    v
Debian live-build
    |
    v
bootable amd64 ISO
    |
    v
virtual-machine testing
```

## Design constraints

- Keep Debian packages and upstream software unmodified where possible.
- Track NEXORA-specific defaults in this repository.
- Avoid embedding credentials, private keys or machine-specific configuration.
- Keep each edition's package selection separate as the project grows.
- Preserve upstream copyright and license notices.
